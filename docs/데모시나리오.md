# 데모 영상 시나리오 (1분 + 원칙 클립)

발표 09장(데모)과 README에 넣을 1분 영상. 체크 항목 6개(화면 전환 · 임의 결과 · json-server GET · 로딩/오류/빈 상태 · 적응형 · 원칙 클립)가 모두 한 번씩 나오게 짰다.

## 찍기 전 준비

- 터미널 1: `cd mock_server && npm run mock` — 화면 오른쪽에 GET 로그가 보이게 둔다. (배포본으로 찍으면 브라우저 개발자 도구 Network 탭을 대신 띄운다.)
- 터미널 2: `flutter run -d chrome`
- Chrome 창을 폰 크기(폭 약 400px)로 줄여 둔다. DevTools 기기 모드를 쓰면 탭할 때 파란 강조가 생길 수 있으니 창 크기만 줄인다.
- 녹화: macOS `Cmd + Shift + 5` → 화면 일부 녹화 (Chrome 창 + 터미널).
- 보관함을 맨 위로 스크롤해 둔다.

## 원칙 클립 p06.mp4 (5~10초)

P06 기억보다 인식 — 본편 0:12–0:34 구간을 짧게 잘라 쓴다.

1. 저장 시트 ‘저장 이유’ 칸에 문장을 쓰는 순간 (2초)
