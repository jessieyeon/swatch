# 원칙 카드

대표 원칙은 **P06 기억보다 인식** 하나로 정했다. 사용자 저니의 감정 최저점(⑥ 저장한 아이디어 검색)에서 나온 원칙이기 때문이다. (은서 결정, 10/28)

## P06 — 기억보다 인식 (Recognition rather than recall)

| 칸 | 내용 |
| --- | --- |
| 원칙 | 사용자가 기억해서 떠올리지 않아도, 화면에서 보고 알아볼 수 있게 정보와 선택지를 보여 준다. |
| 근거 | 저니 최저점 ⑥ 저장한 아이디어 검색(−2) — “보드에 핀이 너무 쌓이다보니까 찾고 싶은 핀이 어디 있는지 잘 모르겠어요” (2026-08-14 ★5) · “이 사진의 어떤 점이 좋았는지 사진마다 구체적으로 메모를 하고 싶습니다.” (2026-01-16 ★5). Pinterest에서는 왜 저장했는지를 사용자가 기억해야 한다. |
| 적용 | S-3 저장 시트 S3-3 `TextField` ‘저장 이유’(`// S3-3 저장 이유 — P06`) · S3-2 유형 추천 칩 · S-1 S1-1 보관함 검색 ‘저장 이유나 태그로 찾기’ · S-2 S2-3 `Card` ‘저장 이유’ · S-6 S6-3 결과에 이유 문장 |
| 시연 | S-3에서 이유를 남기고 저장 → S1-1에서 이유 속 단어로 검색 → S-6 결과에 이유 문장이 함께 보인다. 캡처: [S-3_저장시트.jpg](screenshots/S-3_저장시트.jpg), [S-6_검색결과.jpg](screenshots/S-6_검색결과.jpg) |
| 판단 | 대안 ① 보관함 카드에 이유 2줄(AI 원안) → P08과 충돌해 버림, 이유는 S-2 · S-6에서 본다(쟁점 5). 대안 ② 이유 칸 필수 입력 → 메모를 싫어하는 사용자(Play 08-07 ★1) 때문에 비워도 저장되게 함(쟁점 7). |
